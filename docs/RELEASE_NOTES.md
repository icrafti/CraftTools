# Software Collection 1.1.0

Two portable Windows applications by icrafti, with English interfaces and
documentation:

- **Media Downloader** downloads website video/audio using yt-dlp and handles
  magnet links and `.torrent` files using libtorrent.
- **Audio Converter** converts local audio to MP3, WAV, FLAC, M4A/AAC, and
  OGG/Vorbis. It runs offline and preserves the original file.

Download the matching `*-windows-x64.zip` package, extract it into a writable
folder, and open the EXE. Windows 10/11 x64 is required. Audio Converter uses the
standard .NET Framework 4.x; neither EXE requires a Python installation.
Media Downloader may need Node.js or Deno for some websites.
