# План развития Series Engine

1. **Паспорт готовности проекта.** По каждому языку видно, чего не хватает: реплики, кадра, голоса, тайминга или перевода надписи.
2. **Мастер создания проекта.** Папки, конфигурация и примеры входных файлов создаются из интерфейса.
3. **Импорт озвучки.** Перетащил папку WAV, движок сопоставил файлы с `cue` и показал спорные совпадения.
4. **Карточки персонажей.** Фото, имена по языкам, голос и приметы персонажа доступны из любой сцены.
5. **Библиотека локаций и реквизита.** Повторно используемые референсы мастерской, вагонов, билетов и других предметов.

6. **Сборка одной главы или диапазона `cue`.** Исправил билет на 04:32 и собрал только этот фрагмент.
7. **Предпросмотр раскадровки с голосом.** Сцена проигрывается прямо в браузере, без предварительного рендера MP4.
8. **Монтаж по умолчанию плюс ручные исключения.** Для конкретного кадра можно выбрать крупность, точку склейки или оставить неподвижный план.
9. **Кадрирование вокруг важного объекта.** При смене плана движок держит в кадре лицо, билет или экран.
10. **Вертикальный экспорт.** Из выбранных сцен собирается 9:16 с отдельной настройкой кадрирования.

11. **Проверка синхронизации дублей до рендера.** Список блоков с исходной длиной, целевой длиной и нужным изменением темпа.
12. **Сравнение кандидатов на мастер.** Показывает, при каком основном языке меньше реплик придётся заметно ускорять или замедлять.
13. **Прослушивание проблемных реплик.** Оригинал и подогнанный дубль можно сравнить в два клика.
14. **Переозвучка одной реплики.** После замены WAV движок пересчитает затронутый блок и обновит дорожку.
15. **Словарь произношения.** Имена, вымышленные места и сокращения получают отдельные правила для каждого языка.

16. **Проверка согласованности кадров.** Ищет вероятные ошибки вроде дождя под крышей, смены одежды без причины или билета, повёрнутого от героя.
17. **Разметка надписей мышью.** Можно обвести текст на билете, выбрать наклон и проверить перевод на месте.
    Проверено через HTTP API и в Chrome на билете `G01-015:1` «Седьмого вагона». Выделение, сохранение и возврат к OCR проверены на временной копии кадра.
18. **Сравнение раскадровки со сценарием.** Рядом с каждым кадром видна фраза, которую зритель слышит в этот момент.
    API сверён с таймингами «Седьмого вагона» для всех 197 русских и 201 английского отрезка. В Chrome проверены выбор кадра и перемотка. Отдельно проверены повторный `cue` с разными репликами и отсутствие текста.
19. **Проверка читаемости после кропа.** Помечает важные надписи и предметы, которые стали слишком мелкими или ушли за край.
    Проверено через API и Chrome на «Седьмом вагоне» в 9:16 при 360p и в 16:9 при 1080p. На тестовом отрезке проверены все три типа замечаний и граница склейки общего и крупного планов.
20. **Поиск повторов.** Подсвечивает места, где одна иллюстрация слишком долго держится или часто возвращается.
    API проверен на 197 русских и 201 английском отрезке «Седьмого вагона». В Chrome проверены пустой отчёт реального проекта и оба типа замечаний на тестовой последовательности с копиями под разными именами.

21. **Автоматические субтитры отдельными файлами.** SRT и VTT по языкам на основе готовых реплик и тайминга.
    Проверены выгрузки RU и EN, русский дубль по английскому мастеру, обрезка по диапазону `cue`, скачивание в Chrome и чтение файлов через FFprobe.
22. **Сведение голоса, музыки и шумов.** Музыка приглушается под речь, а уровень озвучки выравнивается между языками.
    Проверены приглушение на тестовых сигналах и смешанный экспорт фрагмента «Седьмого вагона» через API. WAV русского дубля совпал с английским мастером по длительности, исходный режим экспорта проверен отдельно.
23. **Звуковая карта локаций.** У вагона, станции и мастерской свои фоновые звуки, привязанные к сценам.
    Проверено в Chrome и через API на «Седьмом вагоне». В тестовой сборке переключение трамвая на станцию стоит на 10,60 с, длительность WAV дубля совпадает с 19,76 с мастер-фрагмента.
24. **Главы для YouTube.** Движок создаёт список отметок времени по фактическому таймингу мастера.
    Проверено через API и Chrome. Начало второй главы «Седьмого вагона» совпало с таймингом английского (251,56 с) и русского (286,48 с) мастеров. Отдельно проверены валидный список из трёх глав и предупреждение о короткой главе.
25. **Пакет публикации.** MP4, WAV, субтитры, главы, обложки и описания по языкам в одной папке.
    Через API собран двуязычный пакет фрагмента «Седьмого вагона» из 14 файлов. Оба WAV по 5,36 с. В Chrome проверен предварительный отчёт. Также проверены недостающий рендер и выдача видео по диапазону байтов.

26. **Отчёт об ошибках для агентов.** API возвращает код проблемы, язык, `cue`, файл и шаг, который нужно повторить.
    В Chrome и через API проверены общий и английский отчёты «Седьмого вагона». На временном проекте проверены отсутствующий кадр, пропавшая реплика и структурированная ошибка завершённого задания.
27. **Очередь сборок.** Можно поставить несколько проектов на экспорт и следить за их состоянием из одного окна.
    Проверено через API и Chrome на «Седьмом вагоне» и временном проекте. Четыре задания прошли по очереди, ошибка второго задания не остановила следующие, а новое задание принято из UI во время работы очереди.
28. **Возобновление сборки.** После сбоя движок продолжает с нужного этапа, используя уже готовые кадры и дорожки.
    На фрагменте «Седьмого вагона» проверены ошибка при отсутствии русского WAV, повтор после восстановления WAV, сохранение файла английского мастера и выдача обеих ссылок через API.
29. **Сравнение двух сборок.** Видно, какие кадры, реплики, надписи и длительности изменились между версиями.
    Проверены дедупликация повторной сборки, изменения текста и настроек в отчёте API и загрузка сравнения в Chrome. На отдельных данных проверены изменения изображения, надписей и тайминга.
30. **Общие правила качества проекта.** Один профиль задаёт допустимую длину кадра, частоту склеек и язык надписей. UI и агенты используют одни и те же правила.
    Проверены чтение в Chrome, сохранение через API, влияние интервалов на экспорт и отклонение кадра длиннее лимита.
